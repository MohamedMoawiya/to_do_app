# Simple Todo App
a simple task management web application build with Django.

## App Features
1. The application implements CRUD operations for task management.
2. User authentication.
3. User specific task management.

## Technologies Used
* Python
* Django
* SQLite
* HTMX
* HTML
* Bootstrap 5

## Installation 
Clone the repository
```cmd
git clone https://github.com/MohamedMoawiya/to_do_app.git
```
Navigate to the project directory
``` cmd
cd to_do_app
```
Create a virtual environment
```cmd
python -m venv venv
```
Activate the vitrual enevironment
Windows:
```cmd
venv\Scripts\activate
```
Linux/macOS:
```cmd
source venv/bin/activate
```
Install dependencies
```cmd
pip install -r requirements.txt
```
Run database migrations
```cmd
python manage.py migrate
```
Start server
```cmd
python manage.py runserver
```
## Project Purpose
This project was developed as a practical application of Django fundamentals, including CRUD operations, database interaction, request handling, and user authentication.
